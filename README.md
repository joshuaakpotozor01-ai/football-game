# Football Match 3D

A browser-based 3D football game built for Acode and open in a browser. It includes:

- 3D pitch and stadium-style environment
- team selection screen
- loading screen
- score and timer
- player intro sequence
- referee at the center of the match
- game controls and movement
- AI players and goal detection
- whistle, crowd ambience, and simple synthesized music
- reset and restart flow

## Running it

1. Open Acode.
2. Create a folder named `football-game`.
3. Save these files inside it:
   - `index.html`
   - `style.css`
   - `game.js`
4. Open `index.html` in a browser or preview window.
5. Allow the browser to load the JavaScript modules from the CDN.
6. Press the Start Match button.

## Controls

- Keyboard: `WASD` or arrow keys to move.
- `Space` to shoot.
- `P` to pass.
- Mobile: on-screen joystick and shot/pass buttons.

## Notes

This project is intentionally built as a lightweight 3D football prototype so it works well inside a browser and Acode. It uses Three.js and CANNON physics from a CDN.

If something does not load, make sure the browser has internet access and you are opening the `index.html` file correctly.
